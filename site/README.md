# Electrode Change Check Sheet (เว็บคีย์ข้อมูล + กราฟ)

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ต้องมีอินเทอร์เน็ตเพื่อโหลด Chart.js / SheetJS จาก CDN)

- `index.html` โครงหน้าเว็บ
- `css/style.css` หน้าตา
- `js/data.js` ข้อมูลตั้งต้นจากไฟล์ Record_Data_Electrode_1.xlsx + ระบุว่าแต่ละซีตใช้รูป Drawing ไหน
- `js/viewer.js` ดูรูป Drawing เต็มจอ ซูม/ลากได้
- `js/storage.js` บันทึกลงเบราว์เซอร์ + Export/Import Excel
- `js/charts.js` กราฟ
- `js/app.js` ฟอร์มคีย์ข้อมูล, แท็บ, รูปประกอบ
- `images/` รูป Drawing ต้นฉบับ (.jpg ไม่ได้ย่อหรือบีบอัด) และโลโก้

ข้อมูลที่คีย์เก็บไว้ในเบราว์เซอร์เครื่องนั้น (localStorage) – กด Export Excel เก็บสำรองเป็นระยะ

## วิธีใช้
1. เลือกแท็บรุ่น → เลือกวันที่ → ใส่ชื่อผู้บันทึก
2. พิมพ์ค่าชิ้นที่ 1 แล้วกด Enter ไปชิ้นถัดไปเรื่อยๆ (ปุ่ม up/low และ NG กดสลับได้)
3. กด Update กราฟจะแสดงแยกสีตามวัน
4. LSL/USL ใส่แล้วกด 🔒 เพื่อล็อก ไม่ต้องใส่ซ้ำ

รูป Drawing อ้างอิงมาจาก `js/data.js` + `images/` เท่านั้น แก้ในหน้าเว็บไม่ได้

## เพิ่มเติม
- ช่อง Line ในฟอร์มคีย์ (จำค่าล่าสุดให้) เก็บไว้ในทุกแถว และ Export ลงคอลัมน์ N
- ส่วน "ชิ้นก่อนหน้า" แสดง 5 ชิ้นล่าสุดที่บันทึกแล้วเหนือช่องคีย์
- แท็บ "ตารางข้อมูล" กรองตามวันที่/ผู้บันทึก/Line/up-low/NG ได้ และ Export ตารางที่กรองแล้ว
